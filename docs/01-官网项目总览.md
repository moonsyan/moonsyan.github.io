# 🏠 官网项目总览(moonsyan.github.io)

## 一句话

这是 MarkdownSoft(桌面 Markdown 编辑器)的**官网**——一个纯静态网页,部署在 GitHub 免费托管上,网址 `https://moonsyan.github.io`。

> 应用本体是另一个仓库,见 [[06-mkEditor-发布流程]]。

## 技术栈

| 东西 | 用的是什么 |
|------|-----------|
| 框架 | Vue 3(单页落地页) |
| 构建工具 | Vite |
| 语言 | TypeScript |
| 测试 | Vitest |
| 托管 | GitHub Pages(见 [[03-GitHub-Pages]]) |
| 自动部署 | GitHub Actions(见 [[04-GitHub-Actions]]) |

**没有后端、没有数据库。** 部署 = 把静态文件放到 GitHub 的服务器上,用户打开网址就能访问。

## 功能

- **中英双语**切换(默认中文,记忆选择)
- **四套主题**:浅色 / 深色 / 玫瑰 / 海洋
- **8 个特性卡片**、下载按钮(指向 mkEditor 的 Release 页)、页脚

## 目录结构

```
moonsyan.github.io/
├── .github/workflows/deploy.yml   # 自动部署流水线(核心!)
├── public/
│   └── icon.png                   # 网站图标
├── src/
│   ├── main.ts                    # 程序入口,挂载整个页面
│   ├── App.vue                    # 页面骨架:语言/主题切换 + 各区块
│   ├── styles/global.css          # 全局样式
│   ├── themes/                    # 4 个主题文件,每个定义 8 个颜色变量
│   ├── locales/                   # zh.ts + en.ts,29 条文案一一对应
│   ├── composables/               # useI18n(语言)、useTheme(主题)
│   ├── components/                # Hero / 特性卡片 / 下载区 / 页脚
│   └── lib/constants.ts           # 下载链接等常量(改这里)
├── docs/                          # 本知识库
└── package.json
```

## 工作原理(30 秒版)

1. 你往 `main` 分支**推送代码**
2. GitHub Actions **自动**执行 `npm ci` → 构建 → 打包成静态文件
3. 把产物交给 GitHub Pages 发布
4. 用户访问 `moonsyan.github.io`,看到你的官网

每次推代码都会自动重新部署,**不用手动上传任何东西**。

## 两个"动作"最容易搞混

- **部署谁?** 是 Actions 构建出来的 `dist/` 产物,不是仓库里的源码文件
- **谁说了算?** Pages 设置里的"Source(发布源)"决定用哪套产物,见 [[03-GitHub-Pages]]
