# 🛠 本地开发指南

> 先读 [[01-官网项目总览]] 了解整体结构,再动手。

## 环境要求

- **Node.js 18+**(建议 20 或 22,部署用的也是 22)
- 一个终端 + 一个代码编辑器

## 本地跑起来

```bash
# 1. 安装依赖(首次)
npm install

# 2. 启动开发服务器(改代码时保持运行,浏览器实时刷新)
npm run dev

# 3. 打开终端提示的地址,比如 http://localhost:5173
```

## 常用命令

| 命令 | 作用 |
|------|------|
| `npm run dev` | 开发服务器(热更新) |
| `npm test` | 跑测试(改代码后必跑) |
| `npm run typecheck` | 类型检查 |
| `npm run build` | 生产构建,产物在 `dist/` |

**提交前习惯**:`npm test` + `npm run typecheck` 都过了再提交。

## 日常改东西的入口(90% 的需求在这 4 个地方)

### 1. 改文字 / 翻译

**文件**:`src/locales/zh.ts` 和 `en.ts`

- 两条语言的 **key 必须一一对应**(29 条),只在一边改会导致另一边显示英文原文
- 改中文 → 编辑 `zh.ts`;改英文 → 编辑 `en.ts`,两边的 key 保持一致

### 2. 改颜色 / 主题

**文件**:`src/themes/light.css`、`dark.css`、`rose.css`、`ocean.css`

每个主题文件都定义**同样的 8 个变量**:背景、卡片背景、文字、次要文字、边框、强调色、强调色上的文字。

> 想加第 5 套主题:新建 css 文件 + 在 `src/themes/` 目录里参照现有文件,并到 `src/main.ts` 导入、`src/composables/useTheme.ts` 的 `THEMES` 数组加名字。

### 3. 换下载链接

**文件**:`src/lib/constants.ts`

```ts
export const RELEASE_URL = 'https://github.com/moonsyan/mkEditor/releases/latest'
```

把这里换成你的新发布地址即可,全站所有下载按钮会一起生效。

### 4. 放真实截图

现在页面用的是 CSS 画的占位窗口(`src/components/ScreenshotPlaceholder.vue`)。要换成真实截图:

1. 图片放到 `public/` 下(如 `public/screenshot.png`)
2. 修改 `HeroSection.vue`,把占位组件换成 `<img src="/screenshot.png">`

## 提交与发布

```bash
git add .
git commit -m "feat: 改了什么"
git push origin main
```

推送后 GitHub Actions 自动构建部署(见 [[04-GitHub-Actions]]),约 1-2 分钟,去 **Actions 标签页**看进度,绿了即可访问。

## 常见坑

- **改完页面没反应** → 确认 `npm run dev` 还在跑,或者刷新浏览器缓存
- **构建失败** → 先在本地 `npm run build`,能在本地过,线上大概率也能过
- **页面空白** → 多半是发布源配置问题,看 [[03-GitHub-Pages]] 的白屏事故
